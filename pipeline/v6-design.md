# 星图 V6 设计决策

日期：2026-09-23  
适用端：`portal-desktop` Electron + React + Vite  
唯一需求基准：`pipeline/v6-requirements.md`

## 1. 数据模型变更

### 1.1 站改为纯分组容器

- `PipelineNode.stationId` 改为可空：字符串表示属于某站，`null` / `undefined` 表示自由节点。新建普通节点和闸口默认都是自由节点。
- 画布渲染不再把节点声明为 React Flow 的 `parentId` 子节点。站和节点都是绝对坐标实体；`stationId` 只决定分组、站尺寸和低倍聚合，不限制节点脱离站。
- `PipelineStation.nodeIds` 保留为站内顺序提示，成员归属以节点的 `stationId` 为准。拖入、拖出、详情修改归属、批量创建站时会同步维护顺序提示。
- 新增 `Demand.stationLinks` 保存站到站的语义连接。渲染时动态解析为“上一站最后一个节点 → 下一站第一个节点”；任一站为空时先连接站边界，节点加入后自动改接首尾节点。
- 删除自定义站只解除分组，不删除其中节点；V4/V5 已锁定的内置站和节点继续受锁定规则保护。

### 1.2 注意力状态与流程状态分离

节点新增以下可选字段：

| 字段 | 含义 |
| --- | --- |
| `requires_human_review` | 节点本身是否需要人工审核；闸口默认是 `true` |
| `assigned_user` | 当前审核/操作任务分配给谁 |
| `update_seq` | 节点协作更新序号 |
| `last_seen_seq` | 当前用户最后已读序号 |

`PipelineBoardMetadata.currentUserId` 是单机身份占位，当前默认值为 `local-user`。蓝点要求节点处于等待审核、需要人工审核且 `assigned_user === currentUserId`；否则当 `update_seq > last_seen_seq` 时显示灰点。注意力点位于卡片右上角，原有状态色点仍位于节点 topline，两套语义不复用。

### 1.3 星轨列表视图状态

`Demand` 新增 `sortOrder`、`pinned`、`unread`。它们分别支撑组内/跨组拖拽后的稳定顺序、置顶和“标记为未读”。复制星轨会完整复制项目内容，但生成新的星轨 id，取消置顶并标记为未读。

## 2. localStorage 迁移策略

- 存储键继续使用 `beings:star-map:v4`，并继续回读 `beings:star-map:v3`、`beings:pipeline-board:v2`、`beings:pipeline-board:v1`，避免换键造成用户内容看似消失。
- schema 从 3 升到 4。读取 V3/V4/V5 数据时逐条执行宽松归一化：原星轨、节点覆盖、站覆盖、自定义节点/站/连线、坐标、Bug 状态历史和交付物均原样保留；缺失的新字段补默认值。
- 旧节点已有 `stationId` 时保持原归属；只有 V6 新建自由节点或用户主动拖出站时才写入 `stationId: null`。使用显式 `null` 是为了让内置流程节点也能覆盖掉定义中的默认站归属。
- 旧星轨按原数组位置补 `sortOrder`；`pinned`、`unread` 默认 `false`；`stationLinks` 默认空数组；board 身份补 `local-user`。
- 继续使用 V5 的 transition 清洗逻辑。非法或残缺的 `customTransitions` 会被丢弃，但不会因此重置整个星图。
- 写入前仍统一经过 `sanitizePipelineState`，并更新 board 标识为 V6；迁移不删除旧 key，回退版本仍有原始缓存来源。

## 3. 新建、布局与选择

- 新建节点、闸口、站统一由画布把当前可见区域中心换算成 flow 坐标，再减去元素尺寸的一半；缩放和平移后仍落在视口中心并被选中。
- 展开站宽高取内部节点实际右边界/下边界加内边距；空站保留最小标题容器。节点的可见纵坐标至少为站顶端加 112px，避免遮挡站名、说明和节点计数；增删、拖入、拖出后重新计算。
- 左键空白拖拽使用框选；中键和右键拖拽平移。Delete 删除选中节点/站或选中连线；锁定项跳过并提示。
- Alt 开始拖拽时记录选中节点，拖拽结束后在原坐标生成副本并持久化拖动后的位置，避免复制动作打断 React Flow 的活动拖拽。
- 自动排序按选中节点之间的有效 transition 做稳定拓扑顺序：同一站内纵向排列，自由节点横向排列；环路或非连通节点按原稳定顺序收尾。
- 批量详情的公共字段范围为状态、负责人和说明；批量完成仍复用闸口、证据与前置节点校验。

## 4. 右键菜单清单

星图根节点通过捕获阶段阻止系统菜单；应用级编辑菜单同时显式忽略 `#pipeline-view`，避免复制/全选菜单覆盖星图菜单。

### 星轨

- 重命名
- 复制项目
- 置顶 / 取消置顶
- 标记为未读
- 成组（保留 V5，多选时可用）
- 删除星轨（保留 V5，仍禁止删除全部星轨）

### 单节点

- 复制节点
- 转为闸口（锁定节点不改型）
- 标记有更新
- 删除节点

### 站

- 重命名站
- 删除站

### 框选结果

- 复制选中节点
- 自动排序
- 创建站
- 标记有更新
- 删除选中项

### 画布空白

- 新建节点
- 新建闸口
- 新建站

## 5. 侧栏与专注模式

- 左右侧栏收起列宽从 38px 改为 0，侧栏本体完全隐藏。
- 两个控制按钮常驻画布内部左右上方，图标为方框内竖线并左右镜像；侧栏展开时按钮仍在画布内，不依赖侧栏自身。
- 进入专注模式前保存原侧栏状态，然后默认收起两侧栏。专注模式内可用画布按钮临时唤出任一侧栏；退出专注或按 Esc 后恢复进入前的侧栏状态。

## 6. 保留的 V4/V5 行为与验证边界

- 保留节点拖拽连线、连接反馈、低倍站级聚合、专注模式/Esc、闸口推进校验、星轨“状态 · 任务名”、多选成组/删除、Bug 修复组字段与状态历史。
- 详情顶栏不再提供“重置本地编辑”和“关闭”。应用外层功能切换仍提供离开星图的路径。
- 按需求不运行 Electron 图形界面。V6 的本地验证只执行根目录 `npm run typecheck` 和 renderer Vite 生产构建；交互与视觉结果留给负责人真机验收。
