# 星图 V6 需求包

> 本文件是 V6 任务唯一需求基准。负责人醇青 2026-09-23 19:34 口述 11 条反馈整理而成。
> V5 已验收（除 V5 中已知未验完项），V6 不得回退 V4/V5 已验收行为。

## 背景

星图（pipeline 画板）V5 已交付并经醇青真机试用，本轮为第 6 轮迭代。本轮重点：画布交互补齐（框选/中键平移/批量操作）、右键菜单体系、站的定位重构（节点可脱离站存在）、多人协作的未读/待办圆点预留。

## 需求清单

### R1 新建元素出现在视口中心（原第 1 条）
新建站/节点等元素默认出现在**当前画布视口中心**（考虑当前缩放与平移），而不是画布坐标系远端。
- 验收：任意缩放/平移后新建，新元素出现在可见区域中心并自动选中。

### R2 左栏新建简化（原第 2 条）
点击「新建」直接创建一条星轨，落**默认组**，不出现任务名称输入框；创建后再手动分到对应组。
- 验收：一键创建，新星轨出现在默认组，之后可通过拖拽（R3）或右键重命名归组。

### R3 左栏星轨拖拽（原第 3 条）
左栏星轨支持拖拽：组内拖拽排序 + 跨组拖拽移动。
- 验收：拖拽改变顺序/归属，localStorage 持久化，刷新后保持。

### R4 右键菜单体系（原第 4 条）
星图界面内实现自定义右键菜单，屏蔽系统/Electron 默认菜单（复制/全选）的干扰。
- 星轨右键：重命名、复制项目（生成副本）、置顶、标记为未读、删除。
- 节点右键：删除等（其余项 codex 提案，如复制、转为闸口）。
- 画布空白右键：新建节点/新建站（现有能力），不再被全局菜单遮挡。
- 注意：这是对 V5 右键功能（星轨多选成组/删除）的**增强**，不是替换，成组/删除必须保留。
- 验收：星图界面内右键只弹自定义菜单；各菜单项功能生效。

### R5 站展开自适应（原第 5 条）
站展开后尺寸根据内部节点实际占用自适应（含内边距），节点增删后跟随变化。
- 站标题区预留固定高度，第一个节点不得遮挡站名文字（节点从标题下方排布）。
- 验收：1 个/多个节点时站框均贴合内容；站名始终完整可见。

### R6 未读/待办圆点（原第 6 条，多人协作预留）
两类注意力圆点，与现有状态圆点（颜色语义）明确区分（建议用位置/形状区分，如节点右上角小圆点 vs 状态色点）：
- **蓝色圆点** = 需要当前用户操作（节点需人工审核，且审核人是当前用户）。
- **灰色圆点** = 有更新但无需当前用户操作。
- 关键语义：「节点需人工审核」（节点属性，闸口类）与「需自己审核」（分配关系）是两码事，数据模型要分开表达。
- 当前单机先落数据结构与渲染（如 assigned_user / last_seen_seq 字段），多人身份接入后即生效。
- 验收：构造需审核节点显示蓝点；仅状态更新显示灰点；与状态色点不混淆。

### R7 移除「重置本地编辑」与「关闭」按钮（原第 6 条第二条）
详情面板中的「重置本地编辑」「关闭」按钮移除（以现 UI 实际文案为准）。
- 验收：面板无这两个按钮，其余功能不受影响。

### R8 专注模式支持侧边栏（原第 7 条）
专注模式下支持唤出/显示左右侧边栏（交互方式 codex 提案：快捷键或悬浮按钮）。
- 验收：专注模式下能临时看到左栏星轨与右栏详情，退出后恢复全屏画布。

### R9 侧边栏折叠按钮位置与样式（原第 8 条）
- 收起/展开按钮移到**画布内部两侧上方**（贴边），这样两侧栏才能完全折叠。
- icon 用「方框内一根竖线」的 sidebar-toggle 样式，左右镜像，比现在更清晰。
- 验收：两侧栏完全收起后画布全宽；按钮在画布内可见可点。

### R10 站的定位重构（原第 9 条，数据模型变更）
- 站 = 给一批节点加的**分组管理容器**，仅此而已。
- 节点可以不属于任何站（自由节点直接落画布）；新建节点默认**不进站**（落视口中心，配合 R1），拖入站才归属。
- 站与站之间可以节点式连接：连接两个站时，自动把**上一个站的最后一个节点 → 下一个站的第一个节点**连上。
- 站内无节点时的连接行为 codex 提案（如先接站边界，节点入站后自动改接）。
- 验收：新建自由节点不进站；站-站连线后内部节点自动串联。

### R11 画布交互升级（原第 10 条）
- 空白区**中键拖拽** = 平移视图；空白区**左键拖拽** = 框选（xyflow：panOnDrag=[1,2] + selectionOnDrag）。
- 框选后批量操作（右键菜单 + Delete 键）：
  - 复制：ALT+鼠标拖拽 = 拖拽复制副本；
  - 删除：Delete 删除选中；
  - 自动排序：站内选中节点按串行顺序（连线链路序）**上下**排列；画布自由节点按串行顺序**左右**排列；
  - 创建站：把选中节点打成一站；
  - 批量修改详情：右栏批量修改公共字段（字段范围 codex 提案）。
- 验收：中键平移顺滑不与左键冲突；框选后各批量操作生效；自动排序结果符合串行链路。

## 约束

1. **不破坏 V4/V5 已验收行为**：连线拖拽、专注模式进出、闸口节点、星轨标题=状态·任务名、星轨成组/删除右键、bug 修复组状态记录。
2. 模型：gpt-5.6-sol（负责人已拍板 ≥5.6 sol high）。
3. **禁止 electron 图形界面自测**（本机 GPU 子系统缺陷会留僵尸进程占满 Windows 作业配额，曾致 codex 卡死）。验证 = `npm run typecheck` 零错误 + renderer 生产构建通过。
4. localStorage schema 变更必须向后兼容（旧数据迁移，不丢用户已建内容）。
5. 完成后写 `pipeline/v6-design.md`：说明数据模型变更（R6/R10）、迁移策略、各菜单项清单。

## 现状事实（实测）

- 画布库 @xyflow/react 12.11.6；站=父节点/节点=子节点，zoom 阈值控制站折叠↔展开。
- 专注模式 = `pipeline-focus-mode` fixed overlay，Esc 退出；全屏走 Electron IPC `win.setFullScreen`。
- 当前侧栏折叠按钮在侧栏自身上，收起后按钮随侧栏消失（醇青实测痛点，R9 根因）。
- 画布右键新建会被全局复制/全选菜单遮挡（醇青实测，R4 根因方向：星图路由未屏蔽默认 context menu）。
- 代码位置：`desktop/renderer/pipeline/`（page.tsx、models/、v4.css、v5-design.md）；导航入口在 shared/lib/navigation.ts。
- 分支 feature/pipeline 已合并 origin/main（v0.1.5），typecheck 通过，已推线上。
