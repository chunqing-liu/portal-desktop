## P0 Bug（4 条）

### C1 专注模式白屏 + Esc 行为错误

**现象**：点击「专注」按钮后页面上没有内容（真机复现；CDP 复现：点击后 `.pipeline-shell` 无 `is-focus-mode` class、可见节点数为 0）。
**附带 bug**：专注模式下按 Esc 会关掉整个星图面板（应只退出专注）。
**根因（已定位）**：`desktop/renderer/app/page.tsx:57` 的全局 keydown 处理器在 `document` **capture** 阶段监听 Escape，只要 `app.workspace.open` 就 `toggle(false)` 关面板，且无 `preventDefault`；星图的专注退出监听注册在 window bubble 阶段，永远晚一步。另外注意 `shared/components/dialog.tsx` 原生 `<dialog>` 的 cancel 事件也会响应 Esc。
**修复要求**：进入专注态时 Esc 只退出专注，不关面板；不破坏其他视图（chat 等）的 Esc 关闭行为。
**验收标准**：
- 点专注后：shell 有 `is-focus-mode`，画布节点全部可见（20/20），无白屏
- 专注中按 Esc：仅退出专注，面板保持打开、节点可见
- 专注中点退出按钮：同上
- chat 等其他视图的 Esc 行为不变

### C2 折叠按钮位置错误

**现象**：左右栏折叠入口全堆在右上工具栏（当前 `pipeline-page-toolbar` 里的「收起左侧星轨栏」「收起右侧详情栏」）。
**要求**：左栏折叠入口在左栏顶部（贴左边缘），右栏折叠入口在右栏顶部（贴右边缘），带方向 icon（‹ ›）。折叠后入口仍贴边可见、可点击。
**验收标准**：左栏容器内存在折叠按钮且 `getBoundingClientRect().x` 贴近视口左缘；右栏同理贴右缘。

### C3 折叠后边栏占满屏幕

**现象**：点击折叠按钮后边栏反而占满屏幕。
**验收标准**：折叠态左/右栏渲染宽度 ≤ 56px（icon 窄栏），主画布可见宽度占视口 ≥ 80%；再点一次恢复原宽。

### C4 折叠后 icon 丢失

**现象**：折叠后侧栏整个消失，icon 没了。
**要求**：折叠态保留 icon-only 窄栏（约 48-56px，参考 VSCode 活动栏）：星轨列表折叠后显示星轨 icon（hover 出名称 tooltip），详情栏折叠后显示当前选中对象类型 icon。不是整个栏消失。
**验收标准**：折叠态窄栏可见、内部 icon 元素存在、点击 icon 区域可展开。

## 设计项（3 条）

### C5 默认星轨名简化

**现象**：bug 组默认星轨任务名怪（「bug 修复组」类命名）。
**要求**：默认星轨名就叫「bug 修复」，去掉「组」「· 状态」类冗余后缀。检查 templates.ts 默认数据源。
**验收标准**：bug 星轨显示名 =「bug 修复」。

### C6 连线视觉重设计

**现象**：节点-节点、节点-站之间的连接状态不明显。
**要求**：参考 `pipeline/canvas-research.md` 连线设计章节重新设计：
- 连线颜色区分（站间串联 vs 节点间流转）
- hover 高亮、选中加粗
- 必要时加方向箭头
- 保持 bezier 曲线
**验收标准**：连线可见性明显提升（颜色对比度、宽度 ≥ 2px、hover 有视觉变化）。

### C7 节点详情重构

**要求**：
1. 【说明】+【完成证据】统一合并为【描述】，描述作为详情**主要内容**（大文本区域，占详情面板主要空间）
2. 其余小选项/状态（名称、状态、负责人、下一步等）紧凑化：分组或标签行，不再纵向傻傻并列、不占大空间
3. 删除【所属站】字段（无需暴露）
4. 删除【节点需人工审核】字段（闸口已代表人工审核）
5. 评论功能保留（V7 已实现，`details.pipeline-comments` + localStorage `pipeline_comments_v1:<id>`），布局并入新详情设计
**验收标准**：详情面板视觉层级 = 描述主体 + 紧凑元信息；全文无「所属站」「人工审核」字样；评论可展开可发送。
