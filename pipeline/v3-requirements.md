## 4. 画布重构（第5、6点，核心）
迁移到 React Flow（@xyflow/react，已安装 12.11.6），替换自研画布。v2-design.md 已写明自研画布仅用于 V2 原型。

交互要求（对齐 tldraw / Figma / React Flow 行业常规）：
- 滚轮 = 以鼠标位置为锚缩放（zoom-to-cursor）。不再上下滚动。shift+滚轮 = 横向平移；触控板双指 = 平移。
- 平移：左键拖空白处 / 中键拖 / 空格+拖。
- 节点：左键拖拽移动；可拖入站内（自动归为该站子节点）。
- 连线：从节点边缘锚点拖出到另一节点建立连接；连线可选中删除。
- 框选多选、Delete 删除、右键菜单或工具栏新建节点/站。
- 编辑：双击节点或选中后在右侧面板编辑。

## 5. 站-节点层级（第9点，核心）
醇青原话：站是多个节点合并后的统称；站与节点是上下级关系，不是串联。
- 站 = React Flow 父节点（group/subflow），普通节点为子节点，子坐标相对父级。
- 画布缩小（zoom < 阈值）：站折叠成一张站卡片（站名 + 进度摘要），内部子节点隐藏。看到的画布 = 一排站。
- 画布放大（zoom ≥ 阈值）：站展开，显示内部节点。阈值自定（参考 v2 的 0.52/0.9 分档经验），缩放过渡要平滑不跳变。
- 跨站连线画在站层级；站内子节点连线只在其展开时可见。

## 6. 右侧详情面板（第7点）
- 默认折叠/隐藏。
- 点击具体节点时滑出，显示并编辑该节点详情；点击空白处收回。

## 7. 全屏 / 外置浏览器（第3点）
- 病因：页面内 requestFullscreen 在当前 Electron 窗口层级不生效（点击无反应的就是它）。
- 全屏改走 Electron 主进程：IPC → win.setFullScreen(true/false)。
- 外置浏览器：shell.openExternal('http://localhost:<vite端口>/…')。
- 两条都必须实测通过；若在当前架构下做不稳，直接删除这两个按钮（醇青原话：做不好就不做了），不留半残功能。

## 8. 质量门槛
- npx tsc --noEmit 零错误；renderer 构建通过。
- 交互逐条自测并在交付说明里给结果：滚轮缩放锚点、节点拖拽/入站、连线、站折叠展开、右栏开合、全屏/外置浏览器（或已删除）。
- 设计决策写 pipeline/v3-design.md：选型理由、数据模型（站/节点/连线/星轨）、层级折叠机制、迁移中被替换的 v2 代码清单。
