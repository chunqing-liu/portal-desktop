# P13 侧栏折叠按钮重设计（2026-09-24 14:24 醇青反馈）

## 背景（用户原话）
> 这个画布的左右侧面板还是有问题，我希望两侧的折叠展开按钮都在侧边栏里的上方，目前是左侧边栏的展开按钮在中间。然后折叠按钮不需要背景色边框，主要是你做的背景色边框超出界面了，而且它本来只是一个偏小的近似1：1的按钮，你做个背景框给它拉得特别长，你直接抄codex界面的左右展开按钮，codex其实是这么设计的：两个按钮都在顶部栏的两侧角落（就是专注那一行），不占用侧边位置，这样折叠起来的时候就是完全折叠的。

## 现状问题
1. 左侧边栏的展开按钮在侧边栏中间（不在上方）
2. 折叠/展开按钮带背景色边框，背景框被拉得特别长、超出界面
3. 按钮本应偏小、近似 1:1，现在被背景框撑变形

## 目标设计（抄 codex 界面的左右展开按钮）
codex 界面的设计参照：两个按钮都在顶部栏的两侧角落（「专注」那一行），不占用侧边位置，折叠起来的时候侧边栏就是完全折叠的。

具体规格：
1. **位置**：左侧栏的折叠/展开按钮 → 顶栏（专注行）**左上角**；右侧栏的折叠/展开按钮 → 顶栏**右上角**
2. **按钮形态**：偏小、近似 1:1 宽高比；**无背景色边框**（hover 可有轻微视觉反馈，但不要背景框）
3. **折叠语义**：折叠时侧边栏**完全收起**（宽度归零、不占画布空间、不留残条）
4. **位置固定**：按钮一直在顶栏角落，不随侧栏展开/收起移动
5. 左右两个按钮行为对称

## 范围
- 只改折叠/展开按钮的位置、形态和侧栏折叠布局
- 涉及文件自查（page.tsx 按钮渲染、v4.css 样式）
- **不动**：站/节点/星轨数据逻辑、橙框/紫线逻辑（P11 刚修好待验收）、localStorage 结构
- **不动**：专注模式逻辑（顶栏「专注」按钮本身）

## 验收
1. 折叠后侧边栏完全消失，画布占满
2. 按钮在顶栏两侧角落，小尺寸、无背景框、不超出界面
3. 左右按钮对称，各自只控制自己一侧
4. 顶栏（专注行）布局不乱、不与其他控件重叠
5. tsc + renderer 构建通过
