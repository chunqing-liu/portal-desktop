# Portal Desktop 0.1.11 更新

1. **修复历史对话恢复与加载**
   修复本地缓存与 history 接口合并时消息缺失、顺序异常及刷新后内容分批出现的问题。加载期间显示对话骨架屏，完成合并后显示首屏；接口不可用时仍可查看已缓存的对话。

2. **完善场景动态与消息定位**
   场景动态合并客户端所有场景的本地记录与接口最近消息，以简要提问按日期展示；本地存在的场景可点击跳转，并定位到对应消息。

3. **优化长对话与排队消息体验**
   对话按段渲染，上翻时提前加载历史并保持阅读位置，减少抖动；非必要资源按需加载。排队消息支持编辑和拖动排序，工具记录可展开查看执行详情。

4. **增强内容预览与运行稳定性**
   支持异步图片生成的原生图库预览，以及对话内本地文件预览。插件导航图标支持配置；修复智能 UI 续写时的上下文与草稿保留问题，并改善客户端异常退出后的 Portal 恢复。

提供 macOS Apple Silicon、macOS Intel 和 Windows x64 安装包，均内置 Heart Portal。
