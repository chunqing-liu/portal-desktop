# Portal Desktop 0.1.10 更新

本次更新重点改善附件与多模态对话、SBS 状态显示、输入与历史浏览体验，并增强 Windows 安装更新的稳定性。

## 附件与多模态对话

- 支持图片、语音及文件附件的上传、解析、进度显示与失败重试；具体格式的解析能力取决于所连接的服务。
- 支持在客户端侧栏预览 PDF、PPTX、XLSX、文本及 DOCX 解析内容，其他文件可通过系统应用打开。
- 完善附件下载、完整性校验、打开所在位置和下载目录设置。
- 优化取消上传、图片加载和附件历史恢复，减少重复消息与状态闪动。
- 语音附件支持音量、播放速度与下载操作；菜单高度随内容变化，减少多余留白。

## SBS 状态与场景对话

- 将 SBS 自主活动状态集中到对话顶部：执行时绿色图标闪烁，并显示简短状态气泡。
- 切换场景或关闭 SBS 消息正文显示，不会清空正在执行的 SBS 状态。
- SBS 后台活动与当前场景回复分别管理，避免发送按钮被后台推流误切换为停止按钮。
- 场景内不再重复展示 SBS 自主回调过程块；普通对话的思考详情默认折叠，可手动展开。
- 顶部 SBS 设置支持当前场景的正文显示开关，菜单失焦自动关闭。

## 输入与历史浏览

- 输入文字时避免重复重绘历史消息，改善长对话中的输入响应。
- 历史消息按需展开，保持加载旧消息时的阅读位置；修复搜索跳转后中间历史未补齐的问题。
- 修复左侧缩略索引点击后被旧滚动位置拉回、需要重复点击才能跳转的问题。
- 排队快捷键提示显示在发送按钮左侧，不再单独占行或改变输入框高度。
- 保留排队消息从发送到历史确认期间的显示，减少消息闪失与重复。

## Windows 安装与更新

- 加强安装程序交接、后台服务接管及升级失败后的恢复处理。
- 改善 Windows 命令执行中的进度输出，减少无关输出干扰。

提供 macOS Apple Silicon、macOS Intel 和 Windows x64 安装包，均内置 Heart Portal。
