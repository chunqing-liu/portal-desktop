# Portal Desktop 0.1.10

本版本包含 0.1.9 的功能更新，并修复 Windows 后台服务清理已丢失的 PID 文件时误报失败的问题。同步修正启动回归测试的 Electron mock，恢复跨平台发布验证。

## 智能 UI Beta

- 按消息选择是否使用智能 UI，发送后自动关闭本条选择，普通聊天无需反复附带组件上下文。
- 支持可组合的内容布局、表单、图表、清单、SVG 图解和本地隔离运行的交互模拟；控件在客户端实时联动。
- 界面顶部新增“修改”入口：保留输入草稿，携带原页面结构、版本号和当前选择，支持原位增量更新与历史版本预览。
- 优化滑条、卡片、分栏与移动端布局；清单支持分组、动态数量和复制，复制结果通过浮层提示。
- 完善生成协议校验与错误提示，非法更新保留已有可用界面，本地运行失败可重试。

## 对话与场景

- 输入框上方展示待发送队列，支持取消和同场景调整方向；跨场景消息按顺序发送。
- Enter 发送或调整当前回复方向，Ctrl+Enter 排队，macOS 同时支持 Command+Enter；Shift+Enter 换行。
- 改善 SBS 自主消息发现、场景续写、断线恢复及服务端已结束时的等待状态，减少残留排队和重复过程记录。
- 刷新对话显示加载提示并保留现有内容；恢复完整本地历史、场景草稿和对话索引。
- 支持按场景设置 SBS 消息可见性，并优化固定场景列表与对话阅读空间。

## 插件与平台修复

- 插件支持外部 API、系统浏览器打开链接，以及在沙箱内导出下载文件。
- 插件侧栏快捷入口默认隐藏，可按需开启。
- 修复 Windows Portal 接管中的 PID 重用问题，改善任务栏图标随系统主题更新及快捷方式修复。
- 改善 macOS 后台服务被禁用后的恢复，并加入有界后台运行日志。

发布包含 macOS Apple Silicon、macOS Intel 和 Windows x64 安装包，均配套打包 Heart Portal。
