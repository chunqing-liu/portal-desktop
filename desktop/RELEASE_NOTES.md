# Portal Desktop 0.1.9 更新

本次更新带来 Intelligent UI（Beta）、场景内排队回复，以及对话状态、插件能力和客户端体验的改进。

## 1. Intelligent UI（Beta）

让 Being 的回答不止于文字，也能成为可以直接操作的界面。计算器、可勾选清单、图表、SVG 结构图和交互模拟等内容，可以在对话中生成，并在客户端实时响应你的操作。

- 发送消息时，可以按需选择本条使用智能 UI，普通对话不必每次附带智能 UI 上下文。
- 想继续调整生成的页面，点击界面上的「修改」，即可带上当前界面和选择继续对话。
- 详细用法请查看客户端内的示例说明。欢迎多体验、多反馈，帮助我们持续打磨生成效果与交互体验；后续也会配合多模态能力继续更新。

## 2. 修复 SBS 期间的场景会话状态

改善 SBS 自主醒来期间的消息发现、场景状态同步与断线恢复，修复部分会话已结束却仍显示等待或排队的问题，减少重复过程记录，让会话状态更准确。

## 3. 更新客户端插件 SDK

根据使用反馈，补充插件调用外部 API、通过系统浏览器打开链接，以及在沙箱内导出下载文件等能力。插件侧栏快捷入口可按需开启，方便把常用功能接入客户端。

## 4. 支持场景内排队回复

当前回复进行中，也可以在同一场景继续提交消息排队。输入框上方可查看待发送消息，并支持取消排队或调整当前回复方向，让连续对话更顺畅。

## 5. UI 体验与问题修复

- 打磨智能 UI 的滑条、卡片、分栏、清单与窄屏布局；复制结果使用浮层提示，避免挤压页面。
- 优化对话刷新时的加载反馈，以及场景草稿和历史内容恢复。
- 完善智能 UI 校验与更新失败提示，保留已有可用内容。
- 修复部分 Windows、macOS 后台服务及任务栏相关问题，提升客户端稳定性。

提供 macOS Apple Silicon、macOS Intel 和 Windows x64 安装包，均内置 Heart Portal。
