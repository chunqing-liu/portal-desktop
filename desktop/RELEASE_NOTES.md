# Portal Desktop 0.1.10 更新

1. **新增附件上传与预览**
   支持上传图片、音频和文档附件，并预览 PPTX、PDF、XLSX 等文件内容；音频支持播放及解析文字展示。

2. **优化 SBS 与场景对话交互**
   将 SBS 自主行为的状态统一移至顶部，与场景对话区分展示，让对话体验更清晰、流畅。

3. **新增场景对话完成通知**
   支持在场景对话后台处理完成后发送系统通知，点击即可返回对应场景；可在桌面通知设置中开启。

4. **改善对话加载与输入流畅度**
   优化对话流和历史消息加载，改善长对话中输入框输入卡顿等问题。

提供 macOS Apple Silicon、macOS Intel 和 Windows x64 安装包，均内置 Heart Portal。
